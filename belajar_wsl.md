# Catatan Belajar WSL & VS Code

Hari ini saya belajar bahwa:
1. **WSL (Linux)** adalah mesin utama tempat perintah DevOps dijalankan.
2. **VS Code** adalah "kokpit" atau alat bantu untuk menulis kode dengan nyaman.
3. Saya bisa membagi layar terminal (**Split Screen**) untuk multitasking.
4. Perintah `neofetch` menunjukkan identitas sistem operasi Ubuntu saya.

## Perintah yang dipelajari:
- `code [nama_file]` : Membuka file di editor VS Code.
- `sudo apt update` : Memperbarui katalog aplikasi.
- `neofetch` : Menampilkan info sistem dengan logo keren.
