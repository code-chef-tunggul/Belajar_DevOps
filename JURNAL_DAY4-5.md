# Jurnal Belajar DevOps - Day 4 & 5

## Day 4: Package Management
- Belajar `sudo apt update` dan `sudo apt install`.
- Berhasil install `htop` dan `neofetch`.
- Menggunakan Split Terminal di VS Code (`Ctrl + \`).

## Day 5: Process & Service Management
- Mengelola proses dengan `ps aux` dan `grep`.
- Mematikan proses bandel dengan `kill` dan `kill -9`.
- Mengontrol layanan server dengan `systemctl status`, `start`, dan `stop` pada Nginx.
